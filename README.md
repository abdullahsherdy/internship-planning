# Netpoints .NET Backend Internship

This workspace contains the revised curriculum for an eight-session, 24-hour backend internship.

## Documents

- `plan.md`: recommended outcome-driven delivery plan.
- `plan_v2.md`: roster-grounded revision — named track assignments, per-track deliverable matrix, frozen API contract, ADRs.
- `project-blueprint.md`: buildable technical spec of the Task Tracker — code-complete domain/DbContext/controller patterns, sprint backlog with user stories, DB design + index demo, engineering standards.
- `MILESTONES.md`: big-picture milestone map — project, trainee, and instructor tracks per session.
- `PLAN_EVALUATION.md`: assessment of the original plan and rationale.
- `plan-v1.md`: preserved original plan.
- `pre-work/README.md`: delivery schedule and index of send-ready trainee packs.
- `pre-work/00-pre-work-gate.md`: environment and baseline gate before the internship.
- `pre-work/01-session-1-csharp-and-backend-basics.md` through `08-session-8-release-and-demo.md`: actual material to send before each session.
- `teaching-scripts/`: minute-by-minute instructor delivery scripts — all eight sessions (01 final, 02-08 drafts to finalize 24h pre-session; pattern at the end of `01-session-1-script.md`).
- `Trainees info/Trainees_interview_analysis.md`: source trainee profiles.

## Central Outcome

Every graduating trainee independently builds and explains a database-backed ASP.NET Core endpoint with validation, correct HTTP behavior, DTO mapping, async EF Core access, a test, Git evidence, and verified AI assistance.
